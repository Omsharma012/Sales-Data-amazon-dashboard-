# 📊 Amazon Sales Dashboard | Microsoft Excel Data Analytics Project

## 🚀 Project Overview

The **Amazon Sales Dashboard** is a dynamic and interactive Microsoft Excel dashboard built to analyze Amazon sales performance and transform raw transactional data into meaningful business insights. This project demonstrates my ability to clean, analyze, visualize, and present data in a professional dashboard that supports data-driven decision-making.

Designed as part of my **Data Analytics Portfolio**, this dashboard showcases practical Excel skills used by Business Analysts, Data Analysts, and MIS Executives.

---

## 🎯 Business Objective

The goal of this project is to help stakeholders monitor sales performance, identify revenue trends, understand customer purchasing behavior, and evaluate product performance through an interactive dashboard.
